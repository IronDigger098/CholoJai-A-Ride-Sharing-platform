feat(web): scaffold the Next.js application

Creates apps/web on Next.js 16 with the App Router, Turbopack, React 19
and Tailwind v4, wired into the workspace so build, lint, typecheck and
dev pick it up with no per-app configuration.

The placeholder page renders a fare through @cholojai/shared on purpose:
it is the cheapest end-to-end proof that the web app consumes the shared
package's built output.

ADR-014 puts the Tailwind theme in CSS via @theme with no JS config.
ADR-015 keeps one root ESLint config and scopes the React layer with a
factory, because flat config does not cascade.
